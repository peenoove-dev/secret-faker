# SECRET FAKER (เล่นออนไลน์กับเพื่อน · ไทย/English)

React + Vite + Tailwind + เซิร์ฟเวอร์ Node.js ตัวเล็ก (ไม่ต้องลงไลบรารีเพิ่ม)

## มีอะไรใหม่ในเวอร์ชันนี้

- **เล่นกับเพื่อนจริง** — สร้างห้อง ส่งรหัส 6 ตัว (หรือกด "คัดลอกลิงก์ชวนเพื่อน") เพื่อนเข้าห้องจากเครื่องตัวเอง
- **ไม่มีบอทแล้ว** — ไม่มีผู้เล่นปลอม ไม่มีระบบเล่นแทน
- **ภาษาไทย / English** — ปุ่มสลับอยู่มุมขวาบนทุกหน้า (ค่าเริ่มต้นเป็นไทย) คำลับมีทั้งสองภาษา
- **กันโกง** — เซิร์ฟเวอร์เป็นคนตัดสินเกม และไม่ส่งบทบาทคนอื่น/คำลับให้ตัวปลอมมาที่เครื่อง
  (เปิด DevTools ก็ดูไม่ได้)

## รันในเครื่องตัวเอง

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
npm run build
npm start          # เปิด http://localhost:3001
```

ถ้าจะแก้โค้ดไปด้วย ให้เปิดสองหน้าต่างเทอร์มินัล:

```bash
npm run dev:server   # เซิร์ฟเวอร์เกม (พอร์ต 3001)
npm run dev          # หน้าเว็บ (พอร์ต 5173, ส่ง /api ไปที่ 3001 ให้เอง)
```

ทดสอบเล่นคนเดียวได้โดยเปิดหลายแท็บ (แท็บหนึ่งใช้หน้าต่างไม่ระบุตัวตน
เพราะการจำห้องเก็บใน localStorage ซึ่งใช้ร่วมกันทุกแท็บของเบราว์เซอร์เดียวกัน)

## ใส่ออนไลน์ให้เพื่อนเข้าได้ (Render — ฟรี)

1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub (repo ใหม่)
2. สมัคร https://render.com แล้วกด **New → Web Service** เลือก repo นั้น
   - Build Command: `npm install && npm run build`
   - Start Command: `npm start`
   - Instance Type: **Free**
   (หรือกด New → Blueprint ก็ได้ เพราะมีไฟล์ `render.yaml` ให้แล้ว)
3. รอ build เสร็จ จะได้ลิงก์ เช่น `https://secret-faker.onrender.com` ส่งให้เพื่อนได้เลย

ข้อควรรู้ของแพลนฟรี
- ถ้าไม่มีใครเข้า ~15 นาที เซิร์ฟเวอร์จะหลับ ครั้งแรกที่เปิดอาจรอ ~30–60 วินาที
- ห้องเก็บในหน่วยความจำ ถ้าเซิร์ฟเวอร์รีสตาร์ท ห้องที่เล่นอยู่จะหาย (สร้างใหม่ได้ทันที)
- เว็บเดิมบน Netlify โฮสต์เซิร์ฟเวอร์ไม่ได้ ให้ใช้ลิงก์จาก Render แทน
  (ถ้าอยากให้เว็บอยู่ Netlify แต่เซิร์ฟเวอร์อยู่ Render ให้ตั้งตัวแปร `VITE_API_URL`
  เป็นลิงก์ Render ตอน build)

## วิธีเล่น

1. คนหนึ่งสร้างห้อง คนอื่นเข้าด้วยรหัส/ลิงก์ แล้วกด **พร้อม** → เจ้าของห้องกด **เริ่มเกม** (3–8 คน)
2. **เปิดบทบาท** — พลเมืองเห็นคำลับ ตัวปลอมเห็นแค่หมวด (ตัวปลอม 1 คน สำหรับ ≤6 คน, 2 คน สำหรับ 7–8 คน)
3. **คำใบ้** — ผลัดกันพิมพ์คำใบ้คนละหนึ่งคำ
4. **โหวต** — ทุกคนโหวตไล่คนที่สงสัย (โหวตลับจนกว่าจะครบ)
5. เล่นหลายรอบจนพลเมืองไล่ตัวปลอมหมด หรือตัวปลอมมีจำนวนเท่ากับ/มากกว่าพลเมือง

ถ้ามีคนปิดแอป/เน็ตหลุดเกิน 45 วินาที จะถือว่าออกจากเกม (เกมเดินต่อได้ ไม่ค้าง)
รีเฟรชหน้าเว็บได้ จะกลับเข้าห้องเดิมอัตโนมัติ

```
src/
  i18n/       translations.js (ข้อความไทย/อังกฤษทั้งหมด — แก้คำแปลที่นี่)
  context/    RoomContext (เชื่อมเซิร์ฟเวอร์แบบเรียลไทม์)
  pages/      Home, CreateRoom, JoinRoom, Lobby, Game
  components/ UI + components/game/* (หนึ่งไฟล์ต่อหนึ่งเฟส)
```
