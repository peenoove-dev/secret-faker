# SECRET FAKER (เล่นออนไลน์กับเพื่อน · ไทย/English)

React + Vite + Tailwind + เซิร์ฟเวอร์ Node.js ตัวเล็ก (ไม่ต้องลงไลบรารีเพิ่ม)

## เวอร์ชัน v0.7 — โหมดวาดรูป

เจ้าของห้องเลือก **โหมดเกม** ได้ในห้องรอ (ใบ้คำ ⇄ วาดรูป) ก่อนกดเริ่มเกม

**วิธีเล่นโหมดวาดรูป** (3–8 คน, ตัวปลอมมี 1 คนเสมอ)
1. ทุกคนได้หมวดหมู่ พลเมืองเห็นคำลับ (เช่น หมวด "สัตว์" คำลับ "ช้าง") ตัวปลอมเห็นแค่หมวด + รายการคำช่วยเดา 8 คำเหมือนโหมดเดิม
2. ผลัดกันวาดคนละ **หนึ่งเส้น** บนผืนผ้าใบเดียวกัน วน 2 รอบ — ลากนิ้ว/เมาส์ ยกขึ้นคือจบเส้น แล้วกด "ยืนยันเส้นนี้"
   (ยังไม่ยืนยันก็ลากใหม่ทับเส้นเดิมได้) เลือกขนาดเส้นได้ 3 ระดับ ไม่มีปุ่มลบเส้นที่ส่งไปแล้ว
3. แต่ละคนมี **สีประจำตัวคนละสี** (8 สี มีชื่อสีกำกับ) ดูได้ว่าเส้นไหนใครวาด
4. หมดเวลา 25 วินาทีต่อตา เซิร์ฟเวอร์ข้ามตาให้เอง (เกมไม่ค้างถ้ามีคนหลับ/เน็ตหลุด)
5. โหวตหาตัวปลอม **ครั้งเดียวตัดสิน**: จับถูกพลเมืองชนะ (ถ้าตัวปลอมเดาคำลับไม่ถูกจาก 5 ตัวเลือก) จับผิดคนตัวปลอมชนะ
6. จบเกมเปิดเผยภาพรวมที่ทุกคนวาดพร้อมสีของแต่ละคน · คะแนน/อันดับ/ความสำเร็จใช้ระบบเดิม

หมวดคำที่ใช้ในโหมดนี้: สัตว์ อาหาร ของใช้ ยานพาหนะ ผลไม้ (ปรับได้ที่ `DRAW_CATEGORIES` ใน `shared/drawing.js`
ซึ่งเก็บค่าคงที่อื่น ๆ ของโหมดนี้ด้วย เช่น จำนวนรอบ `DRAW_LAPS`, เวลาต่อตา `DRAW_TURN_MS`, สีของผู้เล่น `DRAW_COLORS`)

หมายเหตุทางเทคนิค
- เซิร์ฟเวอร์ตรวจเส้นทุกเส้นก่อนรับ (`sanitizeStroke`: ไม่เกิน 240 จุด พิกัด 0–1000) และตัดสินว่าตาใคร ไม่เชื่อ client
- เส้นของคนอื่นจะ "ค่อย ๆ ถูกวาด" ตอนที่เจ้าตัวกดยืนยัน (ยังไม่มีการแสดงเส้นสดระหว่างที่อีกคนกำลังลากอยู่)
- ตั้งตัวแปร `DRAW_TURN_MS` ที่เซิร์ฟเวอร์เพื่อปรับเวลาต่อตา (หน่วยมิลลิวินาที) ได้โดยไม่ต้องแก้โค้ด

### แก้ไขเรื่องห้องและการเชื่อมต่อ
- เซิร์ฟเวอร์ไม่ crash เมื่อมีคนเรียก URL แปลก ๆ (เช่น `/%`) อีกต่อไป และกันการอ่านไฟล์นอกโฟลเดอร์ `dist` ให้เข้มขึ้น
- ถ้าเซิร์ฟเวอร์ตอบผิดปกติชั่วคราว (เช่น Render กำลังตื่นแล้วตอบ 502) จะ **ไม่ถูกเตะออกจากห้อง** อีกต่อไป — เว็บถามเซิร์ฟเวอร์ (`/check`) ก่อนว่าถูกเตะจริงไหม ถ้าไม่ก็ลองต่อใหม่เอง
- ตรวจจับการเชื่อมต่อที่ค้างเงียบ ๆ (เซิร์ฟเวอร์ส่ง ping ทุก 15 วิ, เงียบเกิน 40 วิ → ต่อใหม่) และต่อใหม่ทันทีเมื่อกลับมาเปิดแท็บ/เน็ตกลับมา
- จำกัดการเชื่อมต่อซ้อนต่อผู้เล่น (4), จำกัดความถี่ สร้างห้อง/เข้าห้อง/ส่งคำสั่ง, ข้อผิดพลาดที่หลุดมาไม่ทำให้ทั้งเซิร์ฟเวอร์ล่ม
- ผู้เล่นที่ออกกลางเกมยังถูกนับสถิติ/คะแนนตามเดิม บัญชีเดียวเปิดสองแท็บในห้องเดียวกันนับคะแนนครั้งเดียว

## เวอร์ชัน v0.4 — บัญชี โปรไฟล์ และระบบผู้สร้าง

- **หน้าล็อกอิน** — สมัคร/เข้าสู่ระบบด้วยชื่อผู้ใช้ + รหัสผ่าน หรือเลือก "เล่นแบบแขก"
- **โปรไฟล์** — เปลี่ยนรูป ชื่อที่แสดงในเกม ดูสถิติ (เกมที่เล่น ชนะ เป็นตัวปลอม)
- **ระบบผู้สร้าง** (`/creator`) — ดูคำทั้งหมดในเกม เลือกหมวด พิมพ์คำ กดเพิ่ม ใช้ในเกมถัดไปทันที
  ปลดล็อกโดยกรอก "รหัสผู้สร้าง" ในหน้าโปรไฟล์ รหัสตั้งที่ตัวแปร `CREATOR_CODE` ของเซิร์ฟเวอร์

### ตั้งค่าบน Render (Environment)
| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `CREATOR_USER` / `CREATOR_PASS` | ชื่อ/รหัสบัญชีผู้สร้างระดับตำนาน (เลเวล 999, ความสำเร็จครบ, เอฟเฟกต์โปรไฟล์) สร้างอัตโนมัติตอนเปิดเซิร์ฟเวอร์ — หรือรันในเครื่อง: `node scripts/seed-creator.js <ชื่อ> <รหัส>` |
| `CREATOR_CODE` | รหัสลับปลดล็อกระบบผู้สร้าง (ไม่ตั้ง = ปิดระบบผู้สร้าง) |
| `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` | เก็บบัญชี + คำที่เพิ่มให้อยู่ถาวร (แนะนำ — สร้าง Redis ฟรีที่ upstash.com) |

⚠ Render แพลนฟรีไม่มีดิสก์ถาวร ถ้าไม่ตั้ง Upstash ข้อมูลบัญชีและคำที่เพิ่มเองจะหายเมื่อเซิร์ฟเวอร์หลับหรือ deploy ใหม่
(ในหน้า Creator มีปุ่มสำรอง/กู้คืนเป็นไฟล์ให้)

#### ระบบบัญชี (แก้ไขล่าสุด)
- **สมัครแล้วหายหลังผ่านไปสักพัก = ยังไม่ได้ตั้ง Upstash** (Render แพลนฟรีหลับหลังไม่มีคนใช้ ~15 นาทีแล้วล้างไฟล์ทิ้ง) → ตั้ง 2 ตัวแปร Upstash ด้านบนแล้ว Redeploy
  เช็กได้ 2 ทาง: เปิด `https://<เว็บของคุณ>/api/health` ต้องเห็น `"storage":"redis"` และ `"persistent":true`
  หรือดู Logs ตอนเริ่มเซิร์ฟเวอร์ต้องมีบรรทัด `[store] mode=redis` (ถ้าเห็นคำเตือน ⚠⚠ แปลว่ายังไม่ได้ตั้ง)
- ตอบ "สมัครสำเร็จ" หลังข้อมูลลง Redis แล้วเท่านั้น ถ้าเขียนไม่สำเร็จจะแจ้งข้อผิดพลาดแทนการทำเป็นสมัครได้แต่ข้อมูลหาย
- ถ้าตั้ง Upstash แล้วแต่ต่อไม่ได้ตอนเปิดเซิร์ฟเวอร์ เซิร์ฟเวอร์จะไม่เริ่มด้วยข้อมูลว่าง (กันเขียนทับบัญชีจริง) และบันทึกข้อมูลให้เสร็จก่อนปิดเมื่อได้รับ SIGTERM
- รหัสผ่าน: scrypt + salt สุ่มรายบัญชี · ชื่อผู้ใช้ไม่ซ้ำแบบไม่สนตัวพิมพ์เล็ก/ใหญ่ (กันสมัครพร้อมกันด้วย)
- เซสชัน: เก็บเฉพาะค่า SHA-256 ของโทเค็น · หมดอายุเมื่อไม่ใช้ 30 วัน / รวมไม่เกิน 90 วัน · ได้สูงสุด 10 เครื่องต่อบัญชี · ออกจากระบบแล้วใช้โทเค็นเดิมไม่ได้
- ตอนเว็บเพิ่งตื่น (502 ชั่วคราว) หน้าเว็บจะลองต่อใหม่เอง ไม่เตะผู้ใช้ออกจากระบบ

## รันในเครื่องตัวเอง

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
npm run build
npm start          # เปิด http://localhost:3001
```

ถ้าจะแก้โค้ดไปด้วย ให้เปิดสองหน้าต่างเทอร์มินัล:

```bash
npm run dev:server   # เซิร์ฟเวอร์เกม (พอร์ต 3001)
npm run dev          # หน้าเว็บ (พอร์ต 5173, ส่ง /api ไปที่ 3001 ให้เอง)
```

ทดสอบเล่นคนเดียวได้โดยเปิดหลายแท็บ (แท็บหนึ่งใช้หน้าต่างไม่ระบุตัวตน
เพราะการจำห้องเก็บใน localStorage ซึ่งใช้ร่วมกันทุกแท็บของเบราว์เซอร์เดียวกัน)

## ใส่ออนไลน์ให้เพื่อนเข้าได้ (Render — ฟรี)

1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub (repo ใหม่)
2. สมัคร https://render.com แล้วกด **New → Web Service** เลือก repo นั้น
   - Build Command: `npm install && npm run build`
   - Start Command: `npm start`
   - Instance Type: **Free**
   (หรือกด New → Blueprint ก็ได้ เพราะมีไฟล์ `render.yaml` ให้แล้ว)
3. รอ build เสร็จ จะได้ลิงก์ เช่น `https://secret-faker.onrender.com` ส่งให้เพื่อนได้เลย

ข้อควรรู้ของแพลนฟรี
- ถ้าไม่มีใครเข้า ~15 นาที เซิร์ฟเวอร์จะหลับ ครั้งแรกที่เปิดอาจรอ ~30–60 วินาที
- ห้องเก็บในหน่วยความจำ ถ้าเซิร์ฟเวอร์รีสตาร์ท ห้องที่เล่นอยู่จะหาย (สร้างใหม่ได้ทันที)
- เว็บเดิมบน Netlify โฮสต์เซิร์ฟเวอร์ไม่ได้ ให้ใช้ลิงก์จาก Render แทน
  (ถ้าอยากให้เว็บอยู่ Netlify แต่เซิร์ฟเวอร์อยู่ Render ให้ตั้งตัวแปร `VITE_API_URL`
  เป็นลิงก์ Render ตอน build)

## วิธีเล่น

1. คนหนึ่งสร้างห้อง คนอื่นเข้าด้วยรหัส/ลิงก์ แล้วกด **พร้อม** → เจ้าของห้องกด **เริ่มเกม** (3–8 คน)
2. **เปิดบทบาท** — พลเมืองเห็นคำลับ ตัวปลอมเห็นแค่หมวด (ตัวปลอม 1 คน สำหรับ ≤6 คน, 2 คน สำหรับ 7–8 คน)
3. **คำใบ้** — ผลัดกันพิมพ์คำใบ้คนละหนึ่งคำ
4. **โหวต** — ทุกคนโหวตไล่คนที่สงสัย (โหวตลับจนกว่าจะครบ)
5. เล่นหลายรอบจนพลเมืองไล่ตัวปลอมหมด หรือตัวปลอมมีจำนวนเท่ากับ/มากกว่าพลเมือง

ถ้ามีคนปิดแอป/เน็ตหลุดเกิน 45 วินาที จะถือว่าออกจากเกม (เกมเดินต่อได้ ไม่ค้าง)
รีเฟรชหน้าเว็บได้ จะกลับเข้าห้องเดิมอัตโนมัติ
